## Overview
Guardian Necklace is a web-based child safety monitoring application designed to support parents in monitoring their children's activities and safety.

The application provides an interactive dashboard that simulates a smart wearable monitoring system. It allows parents to view their children's location, monitor safe zones, access travel history, receive safety notifications, and check device status through a mobile-friendly interface.

Inspired by the concept of smart wearable technology, Guardian Necklace aims to improve child safety awareness through an integrated monitoring interface.

## Features
| Feature | Description |
|---|---|
| 🔐 Login Page | Provides a login interface for parents |
| 🏠 Dashboard | Displays children's profile, safety status, battery level, and device connectivity |
| 📍 Real-Time Tracking | Displays the child's location, coordinates, and location accuracy |
| 🛡️ Geofencing | Displays predefined safe zones and their monitoring status |
| 📋 Travel History | Shows children's daily travel activities through a chronological timeline |
| 🔔 Notifications | Displays safety alerts, battery notifications, and system status updates |
| 🚨 Emergency Alert | Provides an emergency alert interface through an interactive modal |
| 📡 Device Status | Displays device information, battery condition, network connectivity, and sensor status |
| ⚙️ Settings | Provides account, child profile, and application configuration options |

## Built With
- **HTML5** – Structures the application pages and interface components.
- **CSS3** – Handles application styling, responsive layouts, colors, and visual elements.
- **JavaScript (Vanilla JS)** – Implements page navigation, interactive components, modal controls, and application behavior.

## Project Objectives
- Develop a web-based child safety monitoring interface.
- Design an intuitive and user-friendly parental dashboard.
- Provide visual representations of location tracking and geofencing.
- Simulate safety notifications and emergency alert interactions.
- Present smart wearable device monitoring concepts through a web application.

## Project Status

**Status:** Frontend Prototype / UI Demonstration

Guardian Necklace is currently developed as a frontend prototype using HTML, CSS, and JavaScript.

The application demonstrates the proposed user interface and selected interactions of a child safety monitoring system.
